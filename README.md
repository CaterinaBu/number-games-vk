# Игры с числами

Небольшое приложение для VK Mini Apps с четырьмя игровыми режимами на основе числовых фактов.

## Режимы

- Что больше?
- Ближе к правде
- По порядку
- Что ближе?

Одна партия состоит из 10 заданий.

## Данные

В приложении используется статический набор из 1 226 фактов в 8 категориях:

- Животные
- Человек
- Космос
- География
- Архитектура
- Химия
- История
- Культура

## Особенности

- без собственного backend
- хранение локальных рекордов в localStorage
- интеграция с VK Bridge
- межстраничная реклама
- добровольная поддержка через VK
- шаринг и приглашение друзей
- аналитика через Яндекс Метрику
