# Игры с числами

VK Mini App с четырьмя игровыми режимами на основе числовых фактов.

## Режимы

- Что больше?
- Ближе к правде
- По порядку
- Что ближе?

Одна партия состоит из 10 заданий.

## Данные

В приложении используется статический набор из 1 226 фактов в 8 категориях:

- Животные
- Человек
- Космос
- География
- Архитектура
- Химия
- История
- Культура

## Технологии

- VK Mini Apps

## Особенности

- без собственного backend
- хранение локальных рекордов в localStorage
- интеграция с VK Bridge
- межстраничная и баннерная реклама VK
- добровольная поддержка через VK Pay
- шаринг ссылки на приложение
- аналитика через Яндекс Метрику
- автоматический деплой на GitHub Pages

## Разработка

```bash
npm install
npm run dev
```

Сборка production-версии:

